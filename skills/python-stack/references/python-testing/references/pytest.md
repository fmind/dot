# pytest Mechanics

Reuse the project's `pytest` config and task ([python-stack](../../foundation/GUIDE.md) owns the baseline).

1. **Collect & focus**: check discovery via `uv run pytest --collect-only -q <path>` (exit `5` = zero collected), iterate with `uv run pytest -q <path>::<test>` and `--lf`/`--sw`, then rerun the suite.
1. **Quiet, complete output**: run `-q` keeping counts, warnings, failures, and coverage gates ([mise output conventions](../../../../mise/references/task-conventions.md#concise-output)).
1. **Tight assertions & strict config**: parametrize partitions, wrap only the failing call inside `pytest.raises(..., match=...)`, reset mutable state per [Hypothesis example](property-tests.md), inspect skips/deselections, and keep `[tool.pytest] strict = true` (move any `[tool.pytest.ini_options]` keys there — having both exits `4`).

- **Async plugins (`pytest 9.2` + `filterwarnings = ["error"]`)**: startup plugin warnings abort with exit `3`. Use `anyio`'s bundled plugin (`@pytest.mark.anyio` or `anyio_mode = "auto"`, keeping `anyio>=4.15`) when `anyio` is already installed; otherwise add `pytest-asyncio` (`asyncio_mode = "auto"`, `asyncio_default_fixture_loop_scope = "function"` even if unused). Never enable both auto modes.
- **Parallelism (`pytest-xdist`) & coverage (`pytest-cov 7`)**: add `-n auto` only when serial wall time exceeds ~10s on I/O/subprocesses, keeping `-n` out of `addopts` (`-n <N> --pdb` errors; session fixtures run once per worker). Measure via `pytest --cov` (`coverage run -m pytest -n ...` reports `0%`), and enable `[tool.coverage.run] patch = ["subprocess"]` only when `python -m <package>` subprocess tests supply needed coverage — its `sitecustomize` hook adds ~5x overhead on subprocess-heavy `xdist` suites (`coverage combine` before bare `coverage report`).
- **Small plugin set**: `pytest-cov`, `pytest-watcher`, `pytest-socket` (blocks non-loopback connects; gate live tests under `-m integration` + `--force-enable-socket`, never `--disable-socket` which breaks loopback binds), and `pytest-timeout` (`timeout = "60"`, `600` on integration; prefer over `faulthandler_exit_on_timeout = true` which skips teardown/summary). `pytest 9` ships native subtests (skip `pytest-subtests`), `monkeypatch` + `unittest.mock` cover mocking, and `time-machine` (`3.0+`, `@pytest.mark.time_machine(...)`) freezes wall time without breaking `time.monotonic`/asyncio timeouts.
- **Snapshots (`inline-snapshot` + `dirty-equals`)**: use `assert result == snapshot()` for large structured outputs (`--inline-snapshot=create` / `fix` serially outside `xdist`, never in gates, with `[tool.inline-snapshot] format-command = "ruff format --stdin-filename {filename}"`); match volatile fields via `IsUUID()`, `IsDatetime()`, `IsStr(regex=...)`.
