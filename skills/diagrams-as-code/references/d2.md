# D2 Diagram Standard

D2 is the specialist diagram tool: use it when the repository already owns `.d2` sources, the diagram needs bespoke composition (nested containers, boards, scenarios, layers, steps), a standalone SVG, PNG, PDF, PPTX, GIF, or ASCII export is the deliverable, or Mermaid cannot express the visual cleanly. [Diagrams as code](../SKILL.md) owns the format choice.

## Workflow

1. **Write the smallest readable source**: prefer containers, explicit directions, and short labels over manual coordinates.
1. **Choose the layout**: start with `dagre`; try the bundled `tala` (0.9+, orthogonal edge routing for architecture diagrams) or `elk` only when it produces a materially clearer topology (`d2 layout` lists the engines).
1. **Apply the palette**: an Fmind article diagram imports [diagram.d2](../../fmind-visuals/templates/diagram.d2) and uses its classes on a light surface; elsewhere start from a built-in theme (`d2 themes`) and apply the Fmind tokens through `theme-overrides` as in [renderers](../../fmind-visuals/references/renderers.md).
1. **Format, validate, and render** with `d2` declared in the project (`mise use --pin d2`; the workstation does not install it globally), trusting the exit status rather than the presence of an output file:

   ```bash
   d2 fmt diagram.d2
   d2 validate diagram.d2
   d2 diagram.d2 diagram.svg
   ```

1. **Inspect the export**: clipping, crossings, font fallback, contrast, appendix behavior, and whether links or tooltips survive the target embedding.

## Gotchas

- **Prefer SVG over PNG**: use SVG for web pages and documentation; use PNG only for raster-only destinations.
- **Supply all eight `--font-*` flags**: together with custom TTF files so missing weights do not silently fall back.
- **Exports need no browser since 0.9**: D2 renders PNG, PDF, GIF, and PPTX with its built-in renderer; a pin below 0.9 still downloads Playwright Chromium, so raise the pin instead of provisioning a browser.
- **Keep `.d2` beside every generated artifact**: the export is never the editable source.
- **Use Mermaid for GitHub rendering**: switch to [mermaid](mermaid.md) when the source must render inside GitHub Markdown.
