# D2 Diagram Standard

Use D2 when a repo already owns `.d2` sources, needs nested containers, boards, layers, or steps Mermaid cannot express, or delivers standalone SVG, PNG, PDF, PPTX, GIF, or ASCII exports. [Diagrams as code](../SKILL.md) owns format selection and brand rules.

## Workflow

1. **Write minimal source**: use containers, explicit directions, and short labels instead of manual coordinates.
1. **Pick the layout engine**: default to `dagre`; switch to bundled `tala` (0.9+, orthogonal architecture routing) or `elk` only when materially clearer (`d2 layout`).
1. **Apply the palette**: for Fmind work, copy `~/.agents/themes/d2/fmind.d2` beside sources and start with `...@fmind` to apply `DESIGN.md` light-surface `diagram-*` classes (`group`, `container`, `component`, `actor`, `external`, `step`, `terminal`) without inline colors; for customer brands, pick from `d2 themes` and set brand colors via `vars.d2-config.theme-overrides`.
1. **Format, validate, and render** with project-pinned `d2` (`mise use --pin d2`; not installed globally), checking exit codes:

   ```bash
   d2 fmt diagram.d2
   d2 validate diagram.d2
   d2 diagram.d2 diagram.svg
   ```

1. **Inspect the export**: check clipping, crossings, font fallback, contrast, appendix rendering, and link/tooltip survival.

## Gotchas

- **Prefer SVG over PNG**: reserve PNG for raster-only targets.
- **Pass all eight `--font-*` flags**: supply static instantiated TTF weights—Google Sans (`--font-regular`, `--font-italic`, `--font-semibold`, `--font-bold`) and Google Sans Code (`--font-mono`, `--font-mono-italic`, `--font-mono-semibold`, `--font-mono-bold`)—since reusing one variable font renders every slot as regular.
- **No browser needed on 0.9+**: D2 ≥0.9 renders PNG, PDF, GIF, and PPTX natively; upgrade pins below 0.9 instead of installing Playwright Chromium.
- **Keep `.d2` beside exports**: generated files are never the editable source.
- **Use [mermaid](mermaid.md) for GitHub Markdown**: GitHub does not render `.d2` natively.
