# Headless Remote Control

Run Remote Control from the CLI without the desktop app ([docs](https://antigravity.google/docs/remote-control/)). `agy remote-control status` is read-only; `start` registers/restarts and `stop` unregisters. Restart only when idle and verify the browser project picker separately.

- **Session tunnels vs daemon**: `agy --remote-control` or `/remote-control` (`/remote-control off` closes) opens an ephemeral tunnel for one process. The machine daemon runs as user unit `antigravity-cli-daemon` on Linux (`journalctl --user -u antigravity-cli-daemon -n 50`) or an unsupervised background process otherwise; `start --name <name>` sets `cliRemoteControlHostname` (`remoteControlHostname` is desktop-only). Browser Settings sync supported CLI keys back to `settings.json`, while browser "Always allow" approvals write to `config.json`. Requires subscription/org Remote Control access; unsupported under `AGY_ADC_AUTH`.
- **Config reloads and updates**: the daemon reads `~/.gemini/config/config.json` only on start, launched on Linux via a fish drop-in through the [`agy` function](agy/GUIDE.md#managed-setup) (`env.fish` included). Any agy launch can self-update `~/.local/bin/agy`, leaving the daemon on a `(deleted)` `/proc/<MainPID>/exe`; because restarts kill active remote tasks and agy exposes no daemon busy signal, `antigravity-cli-daemon-update.timer` restarts stale binaries at 04:30, and chezmoi apply reloads units without restarting.
- **Project registry**: the picker lists `~/.gemini/config/projects/<id>.json` (`^[a-z0-9][a-z0-9-.:]*[a-z0-9]$`) in `os.ReadDir` order. `dot trust` (run on apply; preview via `dot trust all ~/.local/share/chezmoi --dry-run`) additively registers `trust.agy_projects` from `~/.config/dot.yaml` (default `local-fmind-dot.json` for `fmind/dot`; [daily workflows](../../dot-cli/references/daily-workflows.md)), aborting on malformed JSON. Prefer `/projects` (1.5.0+) to manage folder projects; to reorder or add folderless `--project ID` buckets (unknown IDs fall back to default CLI Project), write `0600` `<id>.json` (`{"id", "name", "projectResources": {"resources": [{"folderUri": "file:///..."}]}}`, or `{}` when folderless; `default-cli-project.json` sorts before `local-<slug>.json`).
- **Conversation index**: agy rebuilds project listings on start from conversation files and summary caches (`jetbox_summaries_proto.pb`, `agyhub_summaries_proto.pb`), so delete conversations inside agy (`F4` in `/resume` or the app menu) rather than unlinking files or editing the index.
