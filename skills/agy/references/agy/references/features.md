# Antigravity Feature Guide

Read the linked page for current controls, prerequisites, and availability; this is a decision map, not a copied manual. Match the installed version and account. Dedicated feature pages can be newer than the overview; verify discovery in the running CLI.

| Need                         | Practical use                                                                                                                                                                                                                                                                                                                                           | Official guidance                                                                                                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Voice                        | `/voice` (`/record`) or F5 dictates into the prompt for editing before submission; Esc discards, and recordings stop at 3 minutes 30 seconds. For SSH, use `agy mic-serve` on loopback with a reverse tunnel and `ANTIGRAVITY_MIC`. Unavailable for business and enterprise accounts and in print mode.                                                 | [Voice and SSH setup](https://antigravity.google/docs/cli/commands/voice/)                                                                                                                                                                             |
| Remote access from a browser | Control host conversations through the web dashboard: `agy --remote-control` or `/remote-control` for one session, or the `agy remote-control` daemon for always-on access without a desktop installation. The host must remain awake and connected.                                                                                                    | [Remote Control](https://antigravity.google/docs/remote-control/)                                                                                                                                                                                      |
| Browser automation           | `/browser` runs the built-in sandboxed Chrome subagent from the CLI; `read_url` grants loading a domain and `execute_url` grants clicking or typing. It does not install an MCP server; for scripted or audited browser work, use the existing chrome-devtools or playwright skill.                                                                     | [Browser tools](https://antigravity.google/docs/ide/browser/) · [Slash commands](https://antigravity.google/docs/slash-commands/) · [Permissions](https://antigravity.google/docs/permissions/)                                                        |
| Models and quota             | Use `agy models` for current choices, `--model`/`--effort` or `/model`/`/effort` for overrides, `/model <name> <prompt>` for a one-shot consult, and `/usage` (`/quota`) for quota. Plan-gated third-party models share the list. `/credits` and `useG1Credits` spend AI credits after plan quota; leave that opt-in to the user.                       | [CLI reference](https://antigravity.google/docs/cli/reference/) · [Models](https://antigravity.google/docs/models/) · [Model quotas](https://antigravity.google/docs/cli/commands/usage/) · [AI credits](https://antigravity.google/docs/cli/credits/) |
| Deep or parallel work        | `/boost` and `/teamwork-preview` offer deeper/parallel reasoning; check plan availability and cost before use. Follow background task and agent panels through completion.                                                                                                                                                                              | [Boost](https://antigravity.google/docs/boost/) · [Teamwork](https://antigravity.google/docs/teamwork/) · [Subagents](https://antigravity.google/docs/subagents?tab=cli)                                                                               |
| Session recovery             | Continue with `agy -c`. `/fork` (`/branch`) copies conversation history, not the checkout or a Git branch; switching the main role in `/agents` also forks, and `/resume` does not undo edits. Use [git-worktree](../../../../git-worktree/SKILL.md) for competing edits and inspect rewind's offered operation before restoring files.                 | [Conversations](https://antigravity.google/docs/cli/conversations/)                                                                                                                                                                                    |
| Review and side work         | `/diff` reviews workspace, turn, or commit changes: `Tab` cycles, `N`/`Shift+N` moves between hunks, and `C` comments. `/tasks` shows background command logs; `/btw <question>` asks a side question without interrupting.                                                                                                                             | [Diff](https://antigravity.google/docs/cli/commands/diff/) · [CLI reference](https://antigravity.google/docs/cli/reference/)                                                                                                                           |
| Code search                  | `/codesearch f:hooks.py fullyIdle` searches workspace files directly, without a separate semantic index. Queries use regex and smart case; `-F` matches literally and `f:`/`-f:` include or exclude globs. `Enter` opens a match, `Ctrl+G` the external editor, and `C` comments on a line; `Esc` then confirm sending delivers line-anchored feedback. | [Code search](https://antigravity.google/docs/cli/commands/codesearch/)                                                                                                                                                                                |
| Terminal ergonomics          | Managed status line/title render state, branch, context, quota, and tasks. `/statusline off` or `/title off` disables them until apply. `/config` controls rendering; `/keybindings` remaps keys. Keep existing Vim preferences.                                                                                                                        | [Status line](https://antigravity.google/docs/cli/statusline/) · [Title](https://antigravity.google/docs/cli/title/) · [Settings](https://antigravity.google/docs/cli/settings/)                                                                       |
| Skills, hooks, and plugins   | Check `/skills` in the live host before moving directories; `/skills reload` rescans without restarting. Inspect `/hooks`, `/permissions`, and `/plugin`; avoid duplicate plugins or per-tool hooks. Workflows retire on 2026-11-01; `/migrate-workflows` converts them to skills.                                                                      | [Customizations](https://antigravity.google/docs/plugins?tab=cli) · [Hooks](https://antigravity.google/docs/hooks/) · [Workflows to skills](https://antigravity.google/docs/migration/workflows-to-skills/)                                            |
| Planning and execution modes | `--mode accept-edits\|plan` or Shift+Tab sets the session mode (`agy --help`; `--effort` also accepts `xhigh` and `max` there); `/plan` drafts a reviewable plan and `/grill-me` interrogates requirements first. Use plan mode for broad or risky edits.                                                                                               | [Execution modes](https://antigravity.google/docs/cli/modes/) · [Plan](https://antigravity.google/docs/plan/)                                                                                                                                          |
| Long-running autonomy        | `/goal` keeps working toward a completion condition, `/schedule` creates timers or cron jobs, and `/learn` turns corrections into rules or skills. Give each a stop condition and review what it persists.                                                                                                                                              | [Slash commands](https://antigravity.google/docs/slash-commands/)                                                                                                                                                                                      |
| Automation and isolation     | Use print mode and structured output for scripts; permissions and terminal sandboxing are separate controls.                                                                                                                                                                                                                                            | [Headless](https://antigravity.google/docs/cli/headless/) · [Permissions](https://antigravity.google/docs/permissions?tab=cli) · [Sandbox](https://antigravity.google/docs/cli/sandbox/)                                                               |

For SDK implementation, use [antigravity-sdk](../../antigravity-sdk/GUIDE.md). For other features, consult the [documentation index](https://antigravity.google/docs/cli/overview/) and `agy changelog`.
