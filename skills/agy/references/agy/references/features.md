# Antigravity Feature Guide

Read the linked page for current controls, prerequisites, and availability; this is a decision map, not a copied manual. Match the installed version and account. Dedicated feature pages can be newer than the overview; verify discovery in the running CLI.

- **Voice**: `/voice` (`/record`) or F5 dictates into the prompt for editing before submission; Esc discards, and recordings stop at 3 minutes 30 seconds. For SSH, use `agy mic-serve` on loopback with a reverse tunnel and `ANTIGRAVITY_MIC`. Unavailable for business and enterprise accounts and in print mode. Official guidance: [Voice and SSH setup](https://antigravity.google/docs/cli/commands/voice/)
- **Remote access from a browser**: Control host conversations through the web dashboard: `agy --remote-control` or `/remote-control` for one session, or the `agy remote-control` daemon for always-on access without a desktop installation. The host must remain awake and connected. Official guidance: [Remote Control](https://antigravity.google/docs/remote-control/)
- **Browser automation**: `/browser` runs the built-in sandboxed Chrome subagent from the CLI; `read_url` grants loading a domain and `execute_url` grants clicking or typing. It does not install an MCP server; for scripted or audited browser work, use the existing chrome-devtools or playwright skill. Official guidance: [Browser tools](https://antigravity.google/docs/ide/browser/) · [Slash commands](https://antigravity.google/docs/slash-commands/) · [Permissions](https://antigravity.google/docs/permissions/)
- **Models and quota**: Use `agy models` for current choices, `--model`/`--effort` or `/model`/`/effort` for overrides (`--model` and `/model` accept a base model name without `--effort` and select its default thinking level), `/model <name> <prompt>` for a one-shot consult, and `/usage` (`/quota`) for quota. Plan-gated third-party models share the list (hidden when an ADC/Business GCP project lacks access). `/credits` and `useG1Credits` spend AI credits after plan quota; leave that opt-in to the user. Official guidance: [CLI reference](https://antigravity.google/docs/cli/reference/) · [Models](https://antigravity.google/docs/models/) · [Model quotas](https://antigravity.google/docs/cli/commands/usage/) · [AI credits](https://antigravity.google/docs/cli/credits/)
- **Deep or parallel work**: `/boost` and `/teamwork-preview` offer deeper/parallel reasoning; check plan availability and cost before use. The built-in `run_workflow` tool runs multi-stage Python orchestration (`agent`, `parallel`, `pipeline`, `phase`) inside a session; prefer standard subagents (`invoke_subagent` with `Workspace="branch"`/`"share"`) or SDK `asyncio.gather` unless in-session multi-stage chaining is required. Follow background task and agent panels through completion. Official guidance: [Boost](https://antigravity.google/docs/boost/) · [Teamwork](https://antigravity.google/docs/teamwork/) · [Subagents](https://antigravity.google/docs/subagents?tab=cli)
- **Session recovery**: [continuation](../../../../task-prompts/references/continuation.md) owns resume, `/compact`, `/context`, and `/fork`. `/branch` is an alias of `/fork`; switching the main role in `/agents` also forks, and `/resume` does not undo edits. Inspect rewind's offered operation before restoring files. Official guidance: [Conversations](https://antigravity.google/docs/cli/conversations/)
- **Review and side work**: `/diff` reviews workspace, turn, or commit history; `C` comments on a line. `/tasks` shows background command logs, timers, and scheduled jobs; `/btw <question>` asks a side question using the current agent without running user/workspace hooks or interrupting the turn. Official guidance: [Diff](https://antigravity.google/docs/cli/commands/diff/) · [CLI reference](https://antigravity.google/docs/cli/reference/)
- **Code search**: `/codesearch f:hooks.py fullyIdle` searches workspace files directly, without a separate semantic index. Queries use regex and smart case; `-F` matches literally and `f:`/`-f:` include or exclude globs. `Enter` opens a match, `Ctrl+G` the external editor, and `C` comments on a line; `Esc` then confirm sending delivers line-anchored feedback. Official guidance: [Code search](https://antigravity.google/docs/cli/commands/codesearch/)
- **Terminal ergonomics**: Managed status line/title render state, branch, context, quota, and tasks; terminals supporting OSC 7501 also receive tab/window status (`AGY_CLI_OSC7501=on|off`, `AGY_CLI_OSC7501_MESSAGES=brief`). `/statusline off` or `/title off` disables the custom renderers until apply. `Alt+M` (`Option+M`) sends a message using the opposite of the `Queued Messages` setting (`Queue` vs `Send Immediately`). `/config` controls rendering; `/keybindings` remaps keys. Keep existing Vim preferences. Official guidance: [Status line](https://antigravity.google/docs/cli/statusline/) · [Title](https://antigravity.google/docs/cli/title/) · [Settings](https://antigravity.google/docs/settings?tab=cli)
- **Skills, hooks, and plugins**: Check `/skills` in the live host before moving directories; `/skills reload` rescans without restarting. Rules have a dedicated 20,000-token budget (`defaultRulesBudget` in `~/.gemini/config/config.json`) and 24,000-byte per-file cap, separate from skills and MCP. Inspect `/hooks`, `/permissions`, and `/plugin` (`agy plugin list --json`, `agy plugin validate [--strict] [--json]`); MCP tools can set `_meta: {"antigravity/alwaysLoad": true}`. Avoid duplicate plugins or per-tool hooks. Workflows retire on 2026-11-01; `/migrate-workflows` converts them to skills. Official guidance: [Customizations](https://antigravity.google/docs/plugins?tab=cli) · [Hooks](https://antigravity.google/docs/hooks/) · [Workflows to skills](https://antigravity.google/docs/migration/workflows-to-skills/)
- **Planning and execution modes**: `--mode accept-edits\|auto\|plan` or `Shift+Tab` sets the session mode (`--effort` accepts `low`, `medium`, `high`, `xhigh`, `max`). `auto` mode (Linux/macOS) approves edits and safe/workspace format, lint, and fix commands autonomously while blocking sensitive egress and reviewing sandbox escapes with a secondary agent (`agy --mode auto --sandbox` for untrusted repos). `/plan` drafts a reviewable plan (skip-permissions no longer auto-approves plans; see `artifactReviewPolicy`), and `/grill-me` interrogates requirements first. Official guidance: [Execution modes](https://antigravity.google/docs/cli/modes/) · [Plan](https://antigravity.google/docs/plan/)
- **Long-running autonomy**: `/goal` keeps working toward a completion condition, `/schedule` creates in-session timers or cron jobs (persistent app/daemon automations live in `~/.gemini/config/sidecars/<id>/sidecar.json`, while OS jobs belong in [scheduled-jobs](../../../../scheduled-jobs/SKILL.md)), and `/learn` turns corrections into rules or skills. Give each a stop condition and review what it persists. Official guidance: [Slash commands](https://antigravity.google/docs/slash-commands/)
- **Automation and isolation**: Use print mode and structured output for scripts; permissions and terminal sandboxing are separate controls. Official guidance: [Headless](https://antigravity.google/docs/cli/headless/) · [Permissions](https://antigravity.google/docs/permissions?tab=cli) · [Sandbox](https://antigravity.google/docs/cli/sandbox/)

For SDK implementation, use [antigravity-sdk](../../antigravity-sdk/GUIDE.md). For other features, consult the [documentation index](https://antigravity.google/docs/cli/overview/) and `agy changelog`.
