# Draft Deliverables

Draft Google Workspace documents, spreadsheets, presentations, Gmail drafts (never send), and 16:9 Typst PDF/PPTX decks. Keep this skill focused on channel plumbing ([gws](../gws/SKILL.md), isolated `077` temp dir); centralize all audience framing, brevity, figure curation, prose craft, visual hierarchy, and `fmind-review-human` pre-send gates in [humanize](../humanize/SKILL.md) and figures in [diagrams-as-code](../diagrams-as-code/SKILL.md).

## Task guides

<!-- guides:start -->

- [doc](references/doc/GUIDE.md): Create or update Google Docs via gws as standard .gdoc or native Markdown .md per user choice.
- [mail](references/mail/GUIDE.md): Draft Gmail emails and replies in recipient's language; never send.
- [sheets](references/sheets/GUIDE.md): Create or update Google Sheets (and optional .xlsx export) via gws sheets and Drive upload.
- [slides](references/slides/GUIDE.md): Create or update native editable Google Slides via gws slides and Drive upload.
- [typst-deck](references/typst-deck/GUIDE.md): Create 16:9 Typst decks, PDF/PPTX, and figure cards; upload via gws.
