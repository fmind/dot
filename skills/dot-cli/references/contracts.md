# Dot Contracts

Configuration precedence is explicit `--config`, then `DOT_CONFIG_PATH`, then `~/.config/dot.yaml`. A missing default uses built-in defaults; an explicit missing file fails. Workstation policy lives under `auth`, `cache`, and `prune`; `dot config show` exposes the complete defaults. Scope lists replace defaults, so override only the lists you change; native tools own credentials. Configuration uses `schema_version: 3` and positive finite numeric seconds in `timeout_seconds` and `probe_timeout_seconds`. Unknown keys are rejected, so delete `auth.github.host` (removed after 9.0.3; GitHub login always targets github.com) with `dot config edit`. Help and config repair commands remain available with malformed configuration.

Requested data goes to stdout; progress and errors go to stderr. Exit codes are 0 for success, 1 for an operational failure or incomplete result, 2 for usage errors (including unknown agent names), and 130 for interruption. Every JSON report has a versioned `schema` envelope; failed operations never become an empty success. Notification hooks, `orphan`, and `secret` never read configuration; hooks always exit 0 and report a failure as one stderr line. Durations such as `7d` and `24h` work across date-filtered commands; zero-length durations such as `0d` exit 2; [daily workflows](daily-workflows.md) owns date boundaries.

Diagnostics use the `dot.diagnostics/v1` envelope; agent doctor details carry `agent`, `hooks`, `source`, `last_sync`, `sync_failures`, `sync_retained`, `archive`, `sessions`, `healthy`, `next`, and `discovery` (`ok`, or `broken:` with `persona`, `skills`, or `agents` when the deployed host files miss the shared persona, skills catalog, or compiled subagents, and `duplicate-skills` when the caller's environment lacks `OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1`, so an OpenCode launched from it loads the catalog twice). Native cache/provider output keeps its native format.

## Session archive

The active `sessions/v3` store keeps one private bundle per agent session, `<agent>/<session_id>.jsonl`: a manifest line (schema 3) with provenance, counts, source signature, and usage, then the normalized records. Sync serializes writers with an owner-only `.write.lock`, checks that no competing capture replaced the observed generation, and publishes the whole file atomically. It retains the archived copy when records disappear or a matching message shrinks. When only a provider token measurement or known cost would become unavailable, it publishes a transcript that does not shrink with the archived usage, records the measuring parser in `usage_parser_version`, counts the session as retained, and retries it on the next sync. Sources that change during parsing fail without publication and retry. Malformed JSONL and usage extraction failures report errors and never replace an archived measurement; the transcript still publishes under the same non-shrink rules, with the archived usage or, for a first capture, without usage, and retries. Missing measurements remain unavailable; explicit zero counters stay distinct from unknown usage, and independently reported cost remains available without claiming complete token pricing. Sync writes parser 10 and reads parser 3 through 10 bundles; earlier parsers have the session status `legacy` until sync recaptures their sources. Usage accounting separately flags parsers 3 through 6, plus parser 7 for Grok, as legacy, judged by the parser that measured the usage; a legacy zero is unpriced because those parsers conflated absent counters with explicit zero. Parser 9 treats an explicitly incomplete Grok ledger as unavailable usage while retaining complete transcript text; malformed metrics still fail. Parser 10 records Claude 1-hour cache writes and Codex per-response usage including compaction requests, treats Claude's `hasUnknownModelCost` as unknown cost, marks subagent transcripts as sidechains of their parent session (`sidechain`, `parent_session_id`), and skips Claude workflow journals. Deeply nested JSON is malformed input, and an unexpandable `~user` project path is a usage error. Previously archived measurements remain retained when an incomplete source cannot safely replace them. Explicit zero counters and recognized Claude synthetic responses are known zero. Recorded cost remains independent. Claude user text blocks and strict provider metric validation remain supported. Earlier stores (such as `sessions/v2`) and standalone usage files are never read or modified. Unsupported bundles fail queries and their capture without replacing them; sync can still capture other sessions.
