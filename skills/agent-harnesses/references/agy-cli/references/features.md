# Antigravity Feature Choices

Workstation policy for `agy` features; consult `antigravity-guide`, `agy --help`, `agy changelog`, or the [docs index](https://antigravity.google/llms.txt) (append `.md` to any docs page) for everything else.

## Modes, Sandboxing & Cost

- **Credits stay opt-in**: `/credits` and `useG1Credits` spend post-quota credits (user-enabled; hidden on business/API-key sessions; `1.5.14+` hides statusline credits at `0`); check plan/cost before `/boost`, `/teamwork`, or user-invoked `/swarm`.
- **`Auto` vs managed `always-proceed`**: new/headless sessions default to `Auto` (`"agentMode": ""` restores `Default`; `toolPermission: "strict"` overrides Auto/accept-edits; `Auto` allows non-workspace reads while writes/denies still apply). Shell substitution/expansion (`$(...)`, backticks, `<(...)`, `{a,b}`) and subcommand flags (`git -c core.pager=`) disable prefix matching and need exact/regex rules. Managed `always-proceed` + `command(*)` in `config.json` override `Auto` and disable the OS sandbox (`read_file(...)` denies do not block shell commands); isolate untrusted repos in a container/VM.
- **Per-session `--sandbox`**: restricts terminal commands without replacing a container/VM for untrusted code (blocks `~/.config` and `~/.git-credentials`, enforces `permissions.deny` at OS mount level; `sandboxProxy.http` pairs `address`+`certFile` for a custom proxy that must enforce `read_url`; [permissions](https://antigravity.google/docs/permissions?tab=cli) vs [sandbox](https://antigravity.google/docs/sandbox/)).
- **`--remote-agent`**: runs off-machine under `/config` → `Remote Agent` (`default`, `accept-edits`, `plan`; exits `2` under `GEMINI_API_KEY`), using `/projects` resources and OAuth plugins while excluding `-p`, `/codesearch`, `/diff`, `/fork`, `/rewind`, `/btw`, `/voice`, `!`, `@` subagents, and local MCP/plugins/skills; use only on request.

## Models, TUI & Voice

- **Model defaults & retirements**: `Gemini 4 Neon` is default for new sessions (512K context; `Neon`/`Hydrogen` add `xhigh`; Claude 4.6 and `GPT-OSS-120b` retire 2026-11-30). Use `/model <model> <prompt>` for one-shot turns and `agy -p "/effort"` for read-only effort inspection (`agy models` lists IDs; [models](https://antigravity.google/docs/models/)).
- **`Orchestrator` roles & effort**: on Pro/Ultra local sessions, `/model`'s `Orchestrator` row configures `Planner` (`Neon`, `Carbon`, `Argon`, `Claude Opus 5.5`), `Executor` (`Hydrogen`, `Claude Sonnet 5.5`), and per-role `Effort` (`Tab`/`Shift+Tab`, `←`/`→`; saved under `"orchestrator"` in `settings.json`; `/effort` does not apply directly). Enterprise and `AGY_ADC_AUTH` stay fixed to Carbon + Hydrogen High (`--model gemini-pro-orchestrator`).
- **Display & shortcuts**: `/thinking [on|off]` (`"showThinking"`) streams thoughts live without `Ctrl+O`. `altScreenMode: "always"` adds click-to-expand, scroll indicator, and column-aware Markdown table copy (trading native scrollback); `"never"` (JSON-only) keeps overlays inline too. See [managed setup](../GUIDE.md#managed-setup) for Zellij-safe shortcuts (`Ctrl+K` fast-approves subagent prompts).
- **Voice & SSH**: `/voice live` (`F6`, `Shift+F6` mute, `F7` stop) and `/voice dictate` or `/record` (`F5`) require personal interactive sessions (disabled under `GEMINI_API_KEY` and business/enterprise); over SSH, run local `agy mic-serve` (`127.0.0.1:4713`), reverse-tunnel it, and start `ANTIGRAVITY_MIC=127.0.0.1:<port> agy` ([voice](https://antigravity.google/docs/cli/commands/voice/)).
- **ACP server**: `agy acp` (`--login`, `--process-per-session`) exposes account models, `auto` mode, and context-window updates; wire editors via [acp](../../../../agent-frameworks/references/acp.md).

## Multi-Agent, Automation & Budgets

- **Subagents, `run_workflow`, & `/swarm`**: prefer `invoke_subagent` (`Workspace="branch"` or `"share"`, copying staged/unstaged/untracked changes up to 100k entries / 4 GiB; max depth 10) or SDK `asyncio.gather`. Reserve `run_workflow` (override bundled Python >=3.8 via `ANTIGRAVITY_PYTHON`; `1.5.14+` allows trailing top-level `return`; `Ctrl+T`/`/tasks` opens phase tree) for scripted fan-out. User-only `/swarm` coordinates peers on `/swarm board` (`Alt+S`, `Alt+X` dismiss; live `Overview` shows up to 6 workstreams on `>= 28`-row terminals).
- **Browser & schedules**: `/browser` connects to Google Chrome in CLI (`.mp4` recordings `1.5.9+`, governed by `execute_url`/`mcp` rules; built-in browser is App-only); use [web-frontend](../../../../web-frontend/SKILL.md) for audited runs. `/schedule` manages session timers/crons while App `/automation` sidecars live in `~/.gemini/config/sidecars/<id>/sidecar.json` (enabled in `config.json`); OS jobs live in [scheduled-jobs](../../../../dot-cli/references/scheduled-jobs/GUIDE.md). Bound `/goal`, `/schedule`, and `/learn` with stop conditions and review persisted output.
- **Recovery & rule budgets**: [continuation](../../task-prompts/references/continuation.md) owns `/resume`, `/compact`, and `/fork` (`/resume` never reverts files; inspect rewind first). Rule budgets: 20,000 tokens (`defaultRulesBudget`) and 24,000 bytes/file after `@[label](path)` inlines (`@filename` rewrites paths only; `1.5.8+` `/learn` checks limits before appending), separate from skills/MCP; legacy workflows stopped loading (`migrate-workflows` is App-only).
