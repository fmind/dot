# Session Compatibility

Read before changing session discovery, parser output, retention rules, or storage. [store.py](../../../../dot/src/fmind_dot/archive/store.py), [sync.py](../../../../dot/src/fmind_dot/archive/sync.py), [parsers.py](../../../../dot/src/fmind_dot/archive/parsers.py), and [query.py](../../../../dot/src/fmind_dot/archive/query.py) are authoritative; always inspect live version constants rather than memory.

## Change boundary

1. **Classify the layer**: source discovery, normalized transcript records, usage extraction, bundle manifest, or queries; check `agent.py` callers and matching tests.
1. **Version bumps**: bump `SESSION_PARSER_VERSION` when normalized output changes for the same source (sync reparses older stored versions, subject to retention). Skip bumping when a change only drops records (e.g., agy `truncated_fields` skip), or retention will keep and retry old bundles forever. Bump `SESSION_SCHEMA_VERSION` or `SESSION_STORE_VERSION` only for bundle structure/layout changes; a store bump requires a non-destructive migration from the prior store.
1. **Replacement invariants**: one bundle per `(agent, session_id)`. Never replace with fewer records or shorter message text (matched by role + timestamp in order), and never overwrite measured usage or known cost with unavailable data (archived zeros stay until remeasured). Non-shrinking transcripts still publish with archived usage: malformed JSONL or failed extraction errors, whereas unavailable measurements record `usage_parser_version`, clear the source signature, and report `retained`. Explicit zero counters and Claude `<synthetic>` turns are known zero; preserve reported cost even without token counts.
1. **Concurrent-write protection**: verify bundle generation under `.write.lock` before replacing (mismatch retains stored bundle). File sources compare size/mtime, retry once if mutated mid-parse, and fail without publishing on a second change; `external_cwd` adapters (agy via `conversation_summaries.db`) append `;cwd=<path>` to the signature and fingerprint (missing metadata preserves the stored `;cwd=`). SQLite sources read one snapshot including WAL and advance their shared checkpoint only after a full, unfiltered pass with zero failures, retained bundles, or source mutations.
1. **Privacy & atomicity**: enforce owner-only permissions, locked read-compare-write with atomic rename, and sanitized path segments. Treat unreadable existing bundles as errors (never absent). Keep real transcript text out of fixtures and errors.
1. **Required tests**: cover repeated sync, truncated chunks, equal-count ties, absent/failed usage, malformed input, schema migration, and unsupported-version failure without clobbering retained data.

## Store layout and parser history

- **Layout (`sessions/v3`)**: `<agent>/<session_id>.jsonl` serialized by `.write.lock`. Schema 4: line 1 manifest (provenance, counts, source signature, `usage_first_timestamp`/`usage_last_timestamp`), line 2 usage JSON or `null`, lines 3+ LF-only records. Schema 3 bundles (embedded usage) remain readable via `READABLE_SCHEMA_VERSIONS`.
- **Reads & edge cases**: metadata reads line 1 only; windowed stats skip session families (parent + sidechains) outside the window. Deeply nested JSON or lone UTF-16 surrogates archive as `partial` rather than failing.
- **Parser milestones**: v10 tags Claude/Codex subagents (`sidechain`, `parent_session_id`) and skips Claude workflow journals; v13 marks unverified agy models `unknown`; v14 preserves raw `isMeta is True` turns as `"meta": true`; v15 uses agy provider-reported request counters. See [agent usage](../../../../skills/dot-cli/references/agent-usage.md#provider-measurement) and [archive contracts](../../../../skills/dot-cli/references/contracts.md#session-archive).
- **Evolution & retirement**: schema 4 readers ignore unknown manifest and top-level usage keys (optional fields with neutral defaults need no schema bump), while `UsageSample` forbids extra keys (needs a parser bump). External bundle readers (such as the brain `agent-sessions` collector) must support a new schema or adapter before release. Preserve [sidechain accounting](../../../../skills/dot-cli/references/agent-usage.md#commands) and never drop a released version from `READABLE_PARSER_VERSIONS` (deleted provider sources cannot be recaptured). Retired harnesses (`RETIRED_AGENTS` in `archive/usage.py`: Codex, Grok) drop their adapter while keeping `--agent` queries, accounting, and `api-prices.yaml` entries intact.
